# درجاتي — نسخة الموقع الحقيقي

هذه نسخة Full-Stack أولية قابلة للرفع على استضافة Node.js.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. داخل مجلد المشروع شغّل:
   npm install
   npm start
3. افتح:
   http://localhost:3000

## بيانات الأستاذ التجريبية
اسم المستخدم: admin
كلمة المرور: 123456

غيّر كلمة المرور والـ SESSION_SECRET قبل الاستخدام الفعلي.

## ما الذي يعمل؟
- دخول الأستاذ.
- إضافة الطلاب والصفوف.
- توليد رقم سري فريد من 3 أرقام.
- إدخال درجات اللغة الإنجليزية.
- الحساب التلقائي لسعي الفصلين والسعي السنوي.
- الحضور: حاضر/غائب/مجاز.
- مواعيد امتحانات حسب الصف.
- عداد تنازلي في بوابة الطالب.
- تبليغات حسب الصف أو جميع الصفوف.
- بوابة الطالب/ولي الأمر للعرض فقط.

## ملاحظة مهمة
قاعدة البيانات SQLite محفوظة في ملف darajati.db. في الاستضافة يجب استخدام تخزين دائم أو نقل قاعدة البيانات إلى PostgreSQL/خدمة قاعدة بيانات مُدارة.


## بيانات دخول الإدارة الجديدة
- A / 1996A1996
- S / 1995S1995

## ملاحظة
لا ترفع `darajati.db` إلى GitHub. قاعدة البيانات الموجودة على Railway يجب الحفاظ عليها.


## الميزات المضافة
- إحصائيات الصف: أعداد الطلبة، الدرجات السنوية المكتملة، متوسط السعي السنوي، والنتائج فوق/تحت 50، وملخص الحضور.
- إشعارات أولياء الأمور: يستمر المعلم بنشر التبليغات من قسم إشعارات أولياء الأمور، وتظهر للطالب/ولي الأمر بعد إدخال الرمز الثلاثي.
- الملازم التعليمية: يستطيع المعلم رفع ملفات PDF حتى 30MB وتحديد صفها، ويستطيع الطالب تنزيل ملازم صفه من بوابة الطالب.
- يتطلب رفع الملازم تخزينًا دائمًا على الاستضافة؛ ملفات النظام المحلي قد تضيع عند إعادة النشر إذا لم تُضبط وحدة تخزين دائمة في Railway.
- حافظ على ملف قاعدة البيانات `darajati.db` ولا تستبدله عند تحديث المشروع.
- حسابات الإدارة: `A / 1996A1996` و `S / 1995S1995`.
