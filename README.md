# درجاتي — نسخة الموقع الحقيقي

هذه نسخة Full-Stack أولية قابلة للرفع على استضافة Node.js.

## التشغيل
1. ثبّت Node.js 20 أو أحدث.
2. داخل مجلد المشروع شغّل:
   npm install
   npm start
3. افتح:
   http://localhost:3000

## بيانات الأستاذ التجريبية
اسم المستخدم: admin
كلمة المرور: 123456

غيّر كلمة المرور والـ SESSION_SECRET قبل الاستخدام الفعلي.

## ما الذي يعمل؟
- دخول الأستاذ.
- إضافة الطلاب والصفوف.
- توليد رقم سري فريد من 3 أرقام.
- إدخال درجات اللغة الإنجليزية.
- الحساب التلقائي لسعي الفصلين والسعي السنوي.
- الحضور: حاضر/غائب/مجاز.
- مواعيد امتحانات حسب الصف.
- عداد تنازلي في بوابة الطالب.
- تبليغات حسب الصف أو جميع الصفوف.
- بوابة الطالب/ولي الأمر للعرض فقط.

## ملاحظة مهمة
قاعدة البيانات SQLite محفوظة في ملف darajati.db. في الاستضافة يجب استخدام تخزين دائم أو نقل قاعدة البيانات إلى PostgreSQL/خدمة قاعدة بيانات مُدارة.
